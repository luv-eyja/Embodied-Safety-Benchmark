# 覆盖与证据缺口登记

截至 2026-11-03，分类清理、统一比较矩阵和旧统计修正已经完成。以下是继续完善调研的证据待办，不代表已证明相应领域缺少工作。

## 1. 代表性补查（下一步优先）

62 个重点条目中，33 项带机械臂操作标签、6 项带移动操作标签；标签可重叠。导航、人机交互、工业装配各 2 项，全身控制、多机器人、无人机各 1 项，自动驾驶 5 项。当前样本不均衡，不能声称全面覆盖具身智能。

| 方向 | 需要补查的问题 |
|---|---|
| 导航、移动操作 | 是否测动态行人、社会规范、地图外变化、长期任务和真实部署？ |
| 全身、灵巧操作 | 是否分别测稳定性、接触、损伤和人体风险？实体任务件是否附可执行协议和基线？ |
| 人机交互、多机器人 | 是否测物理交互或机器人协调，还是只测问答、仿真代理？ |
| 无人机、工业装配 | 是否覆盖故障、约束违反、恢复，以及任务成功与安全双轴？ |
| 自动驾驶 | 区分平台、离线感知、非反应式评分、闭环驾驶与对抗场景，并明确纳入范围。 |

从[当前成员列表](../design/coverage-matrix.md)做前后向引文追溯，同时补经典代表和近期工作。保留数据库、检索日期、完整检索式、命中数、去重和逐篇纳入／排除理由。有项目入口是实现核查的优先条件，不是论文质量判据；无确认入口者仍进入非重点档案。

验收：每个分支有覆盖理由或明确的排除范围，不只按每类凑篇数。完成这一流程前，不称本库为系统综述。

## 2. 资源与协议验收（P1）

| 核查项 | 应保存的证据 | 当前状态 |
|---|---|---|
| 代码、评测器 | 官方归属、提交／发布版本、任务定义、成功／违规判定代码位置 | 仅入口审计，未逐项目验收 |
| 数据、资产 | 下载版本、任务清单、分割、额外资产和审批条件 | 未统一核验 |
| 许可证 | 代码、数据、资产各自的许可文件 | 未统一核验 |
| 基线、运行条件 | 模型检查点、依赖、控制频率、种子、硬件、单次成本 | 笔记有部分信息，尚未形成完整审计 |
| 统计协议 | 配对单位、分母、重复数、置信区间、失效归类 | 已记录已知及待核边界，仍需补齐 |
| 最小运行 | 命令、日志、产物、失败原因和协议偏离 | 未运行，不标为已复现 |

文献调研可以先完成静态核查。若结论依赖实际可运行性，再选择少数代表做最小复现，不必先跑完全部基线。

## 3. 影响力与实际采用（P1）

引用快照已是 62 项观测，并且每条都查了引文清单与 arXiv 摘要命中（见[引文与摘要命中清单](benchmark-citing-papers.md)）；这仍然不能解释为 62 项独立采用。对综述主线的代表，逐篇区分只提及、原作者自用、独立运行、用于训练和正式比较。记录论文、实验章节／表格、任务版本、作者关系和采用方式。未取得证据时写“未查到”，不写“无人采用”。

LIBERO-Para、RoboCasa、CARLA 的计数已于 2026-11-04 补齐。补数不替代采用审计，不同版本的计数仍不相加。下一步可以从这里开始：20 个有引文的条目，各取被引最高的若干篇引文论文，逐篇打开标注它是在该 benchmark 上跑实验、只作背景引用，还是原作者自用。

## 4. 综述与选型交付（P2）

在[比较矩阵](benchmark-comparison.md)基础上按问题组织：语义安全、物理执行安全、扰动鲁棒性、长时程与恢复、跨本体／真机有效性、治理与邻接软件代理。每组说明适用对象、执行层级、关键技术、互补关系和不能回答的问题，并引用原论文。

验收：读者能根据问题选出一组互补基准，理解接入成本和分数边界；“领域空白”“首次”“唯一”须有专门检索证据。开发新基准可另立课题，不是本次调研的必选交付。

- 已完成：62 项分类及理由、指标含义与分母、执行层级、对照与统计边界、来源连接、筛选总表和一致性校验。
- 未完成：全领域系统检索、双人独立编码、资源验收、独立采用审计、实验复现、完整综述选型结论。
- 非重点 60 项继续存档；未找到已确认入口不等于绝对没有仓库。
