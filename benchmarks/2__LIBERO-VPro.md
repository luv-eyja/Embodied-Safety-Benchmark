# LIBERO-VPro

> **所属环节**：感知（执行期视觉证据）  
> **分类**：VLA 鲁棒性  
> **关联论文**：本表 1 篇（提出者 1 篇，使用者 0 篇）

## 1. 测什么问题（内容与所测环节）

标准基准默认执行全程的视觉观测都是干净、及时且一致的；真实系统里视觉证据会退化、延迟、来源不一致。

## 2. 怎么构建的

四个互补维度：视觉证据退化（Visual Evidence Degradation）、相机陈旧/延迟（Camera Staleness）、视觉源一致性（Visual Source Consistency）、任务相关场景变化（Task-Relevant Scene Variation），共 **12 类挑战、96 种设置、3,296 个任务-条件案例**，约 **196,000 个仿真回合**，另加 200 次 Franka Research 3 真机 rollout。

## 3. 用这个基准测了什么

3 个 VLA + 3 个世界动作模型（WAM）。

## 4. 关键结论与改进方向

**关键结论**：**强劲的名义性能并不保证闭环视觉鲁棒性**；视觉证据的时序特性（陈旧度）与一致性是独立于噪声/退化的失效来源。

**论文提到的改进方向**：①把时序视觉质量（延迟、丢帧、来源不一致）纳入评测；②仿真与真机需并行验证；③世界动作模型与 VLA 需在同一视觉扰动谱下比较。
